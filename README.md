# 🚀 TraceMaster（TrailFlow）PRD V5.0（最终版）

> 安卓轨迹记录应用：以“稳定性 + 低功耗 + 流畅体验”为核心的 MVP 到可发布版本方案。

## 一、产品概述

### 1.1 产品定位
TraceMaster 是一款面向跑步、徒步、骑行场景的专业轨迹记录与分析工具，强调后台稳定记录、低功耗和无干扰体验。

### 1.2 核心价值
- 稳定可靠：轨迹不断点、不丢失。
- 极致省电：长时间记录无焦虑。
- 流畅体验：低延迟、不卡顿、状态清晰。
- 无干扰：无广告、无打断。

### 1.3 产品原则
1. 稳定性 > 功能数量
2. 功耗是第一体验指标
3. 核心操作 ≤1 步完成
4. 离线优先
5. 异常可感知但不打断

## 二、目标用户与场景

### 2.1 MVP 用户
- 跑步 / 徒步 / 骑行用户
- 对轨迹精度、续航敏感用户

### 2.2 核心场景
1. 一键开始记录
2. 实时查看速度/距离/时长
3. 结束后查看轨迹与统计
4. 生成海报并分享

## 四、核心功能设计

### 4.1 轨迹录制系统

#### 功能
- 一键开始 / 暂停 / 结束
- 前台服务 + 后台持续录制
- 实时展示距离、时间、速度、精度状态

#### 状态驱动定位策略
| 状态 | 采样间隔 |
|---|---|
| 静止 | 10s |
| 慢速 | 3s |
| 高速 | 1s |

#### 数据流程
`定位 -> 数据过滤 -> 缓存 -> 批量写入`

#### 点位结构
```json
{
  "lat": 39.9,
  "lon": 116.3,
  "time": 1710000000,
  "speed": 2.4,
  "accuracy": 8.0
}
```

#### 性能指标
- 启动录制响应 < 300ms
- GPS 首次定位 < 2s
- 丢点率 < 1%
- 崩溃率 < 0.05%

#### 功耗指标
- 标准模式 ≤ 5% / 小时
- 省电模式 ≤ 3% / 小时

#### 异常处理
- GPS弱：自动降级 + 顶部提示
- 进程被杀：服务恢复 + 会话补写
- 低电量：自动进入省电模式

### 4.2 回放系统
- 地图轨迹展示、轨迹播放、基础统计
- Douglas-Peucker 降采样、分段加载、首屏快速渲染
- 目标：加载 < 1s、首帧 < 500ms、帧率 ≥ 55FPS

### 4.3 分享功能
- 自动生成轨迹海报
- 包含轨迹图、距离、时间、配速
- 海报生成耗时 < 1s

## 六、技术架构

### 6.1 分层
`UI -> ViewModel -> UseCase -> Repository -> Local Storage`

## 十三、构建排障（Build Troubleshooting）

### 13.1 `org.gradle.java.home` / `JAVA_HOME` 报错
- 现版本不再在 `gradle.properties` 中硬编码 `org.gradle.java.home`。
- 请在本机设置 `JAVA_HOME` 指向 **JDK 17+**。
- 可先执行：`echo $JAVA_HOME && $JAVA_HOME/bin/java -version`。

### 13.2 依赖下载 `403 Forbidden`
- 若构建输出中出现仓库 `403`，通常是网络策略或代理限制，不是业务代码语法错误。
- 建议检查公司网络白名单/代理策略，确保可访问：
  - Google Maven (`https://dl.google.com/dl/android/maven2/`)
  - Maven Central (`https://repo.maven.apache.org/maven2/`)
- 可优先运行 `./build_apk.sh`，脚本会在失败时给出定向提示。

### 13.3 地图功能不可用
- 若自检中显示地图功能不可用，通常是 `AndroidManifest.xml` 中地图 Key 仍为 `YOUR_*` 占位值。
- 请替换为真实 API Key 后再进行真机验证。

### 13.4 新电脑首装（仅安装 Android Studio）快速检查
- 打开 Android Studio 一次，确保 SDK 与默认 JBR 下载完成。
- 在项目根目录执行：`./build_apk.sh`（Windows Git Bash / macOS / Linux）。
- 若提示 `JAVA_HOME` 问题，优先使用 Android Studio 默认 JBR 或手动设置 `JAVA_HOME` 到 JDK 17+。
- 若提示缺少 `gradle`，建议在 Android Studio 中执行一次 Gradle 同步并补齐 `gradlew` wrapper 文件。
