# 城市狂飙（GTA 风格网页小游戏）

一个纯 HTML/CSS/JavaScript 的单文件小游戏。

## 运行方式

直接双击 `index.html`，或者在当前目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作说明

- `W` / `↑`：加速
- `S` / `↓`：减速 / 倒车
- `A` / `D` 或 `←` / `→`：转向
- `Space`：手刹漂移

## 玩法

- 收集金币提升分数。
- 随时间增长与拾取金币，通缉等级会升高。
- 通缉等级越高，追捕警车越多。
- 耐久降为 0 游戏结束。
